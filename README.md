# C++ Name Sorter

This program sorts a list of 20 names in alphabetical order using **Selection Sort** and custom string handling functions (without using the C++ standard string library).

## Features
- Custom `stringLength`, `stringCopy`, and `stringCompare` functions
- Selection Sort implementation for 2D character arrays
- Sorts names in the format "Last, First"

## How to compile and run
```bash
g++ main.cpp -o sorter
./sorter
```
